작업을 하면서 구성에 대한 시각화를 할 일이 많이 있다. 그럴때마다 보통은 freeform 이나 figma 를 이용해서 작성을 했었는데 숙련도 이슈로 생각보다 시간이 오래걸렸다. 그러다보니 매번 시각화는 뒤로 미루기 일쑤였다.

www.mermaidchart.com, mermaid.live 사이트 차이

여러가지 타입의 다이어그램 가능

Mermaid는 마크다운에서 영감을 받은 텍스트 정의와 렌더러를 사용하여 복잡한 다이어그램을 만들고 수정하는 JavaScript 기반 다이어그램 및 차트 작성 도구입니다. Mermaid의 주요 목적은 개발 속도에 맞춰 문서를 작성하는 것입니다.

언제 만들어 졌을까?

vscode 익스텐션 존재
copilot 에서 생성도 가능

https://icon-sets.iconify.design/ 아이콘 쓸 수 있음

근데 일단 웹에서는 아이콘을 못쓰고 (기본 5개만) vscode 익스텐션에서는 logos 같은거만 쓸 수 있고
결국엔  직접 import 해서 써야함
