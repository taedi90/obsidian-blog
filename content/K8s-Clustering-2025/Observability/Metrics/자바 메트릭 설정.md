## OpenTelemetry SDK javaagent 추가

검색해보니 trace_id와 span_id를 쓰려면 MDC, Spring Cloud Sleuth, Micrometer Tracing 같은 라이브러리를 추가하고 별도 설정을 해야 한다는 글들이 있었다. 근데 의외로 OpenTelemetry SDK를 javaagent로 등록만 해주면 간단하게 설정이 됐다.

```bash
-javaagent:/opentelemetry-javaagent.jar 
-Dotel.resource.attributes=service.name=test-api 
-Dotel.traces.exporter=otlp 
-Dotel.exporter.otlp.endpoint=http://otel-collector-opentelemetry-collector.otel-collector.svc:4318
```

javaagent를 붙이면 HTTP 요청, JDBC 쿼리, gRPC 호출 등이 자동으로 trace에 잡힌다. 애플리케이션 코드를 건드릴 필요가 없다.

## 메트릭

메트릭도 같은 javaagent가 수집한다. JVM 메모리, GC, CPU 사용량을 기본으로 잡아주고, Micrometer로 추가 메트릭을 노출하면 그것도 가져간다.

수집된 메트릭은 OTLP 프로토콜로 otel-collector에 전송되고, collector가 SigNoz(ClickHouse)로 넘긴다.
