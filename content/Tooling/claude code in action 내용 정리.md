## 🧠 1. Claude Code는 무엇인가요?

Claude Code는 인간 개발자를 도와주는 <b>AI 기반 코딩 어시스턴트</b>입니다. 일반적인 챗봇과는 다르게 단순한 대화뿐 아니라, <b>실제 개발 환경과 연동된 다양한 작업</b>을 수행할 수 있습니다. Claude는 직접 시스템 명령을 실행하거나 파일을 읽지는 못하지만, 필요한 작업을 <b>"도구(tool)" 형태로 요청</b>하고, 사용자는 그 요청을 실행한 결과를 다시 Claude에 전달하는 구조로 동작합니다.

예를 들어:

- 사용자가 "이 오류를 고쳐줘"라고 하면,
- Claude는 관련 파일을 읽고, 오류 메시지를 분석하고, 수정 방향을 계획한 뒤
- 수정이 필요한 파일과 내용을 알려주고,
- 사용자는 실제 수정을 수행하거나 Claude가 작성한 수정 코드를 적용합니다.

---

## ⚙️ 2. Claude가 도구를 사용하는 방식

Claude는 아래처럼 순차적으로 작업을 수행합니다.

1. <b>사용자의 요청</b>을 받습니다. (예: “이 함수 고쳐줘”)
2. 필요한 맥락(코드, 파일 등)을 <b>읽거나 분석</b>하려고 시도합니다.
3. Claude는 “이 파일을 읽어야겠다”라고 판단하면, `read: 경로/파일이름` 형식의 명령을 생성합니다.
4. 이 요청을 Claude Code가 실행해서 파일 내용을 Claude에 넘겨줍니다.
5. Claude는 받은 정보를 바탕으로 <b>수정 코드, 분석, 설명</b> 등을 제공합니다.

이런 시스템을 통해 Claude는 <b>실제 파일을 직접 건드리지 않고도</b>, 마치 개발자처럼 프로젝트 전체를 이해하고 수정하는 역할을 할 수 있습니다.

---

## 💡 Claude Code의 특징

- <b>도구 사용 능력이 매우 뛰어남</b>: 다른 AI보다 복잡한 개발 도구 사용을 더 잘 이해하고, 결합해서 사용할 수 있습니다.
- <b>보안 강화</b>: 코드를 외부 서버에 보내지 않고, 직접 로컬 파일을 검색해서 분석하기 때문에 민감한 프로젝트에도 적합합니다.
- <b>확장 가능</b>: 필요한 기능이 있다면, 새로운 도구를 쉽게 추가할 수 있습니다.

## 🔍 Claude Code 실제 사용 예시

### 1. 코드 성능 개선
Claude는 유명 자바스크립트 라이브러리인 <b>Chalk</b>를 분석해 병목을 찾아냈고, 자체적으로 수정 방향을 제안하여 <b>성능을 3.9배 향상</b>시켰습니다.

### 2. 데이터 분석
CSV 데이터를 분석해 <b>이탈 사용자 패턴(Churn)</b> 을 파악하는 작업도 수행했습니다. Claude는 주피터 노트북을 사용해 셀을 실행하고, 결과를 보고 반복적으로 분석을 이어갑니다.

### 3. 브라우저 자동화
Claude는 브라우저를 자동으로 열고 UI 스타일을 분석해 개선합니다. 예를 들어, Claude는 UI의 스크린샷을 보고 어떤 색상이 어울리지 않는지 판단한 뒤, 스타일을 바꾸도록 안내합니다.

### 4. 인프라 리뷰
AWS 인프라를 정의한 Terraform 코드를 분석해, <b>외부로 노출될 수 있는 개인정보(Pll)</b> 를 감지했습니다. 코드에 포함된 이메일이 외부 파트너와 공유되고 있었는데, Claude가 이를 자동으로 인식하고 경고했습니다.

## 🧩 Claude의 컨텍스트(context) 관리

Claude가 제대로 일하려면, 프로젝트의 구조나 핵심 파일 같은 <b>맥락 정보(context)</b> 를 잘 전달받아야 합니다.

- <b>/init 명령어</b>: 프로젝트를 처음 분석할 때 사용하며, `Claude.md`라는 파일을 만들어 구조, 핵심 파일, 주요 개념을 요약해둡니다.
- 이 파일은 항상 Claude에게 전달되어 <b>작업 시 참고 정보</b>로 사용됩니다.
- `@파일명` 을 써서 특정 파일을 Claude에 명시적으로 전달할 수 있습니다.
- `#`을 이용하면 자연어로 `Claude.md` 내용을 편집하거나 추가할 수 있습니다.

→ 중요한 DB 스키마나 API 문서 등을 `Claude.md`에 넣어두면 항상 인지하고 작업을 수행합니다.

## ✏️ 코드 변경 워크플로우

Claude를 활용해 코드를 수정할 때는 다음과 같은 기능들이 제공됩니다.

- <b>스크린샷</b> 붙여넣기: 수정할 UI 화면을 Control+V 로 붙이면 Claude가 해당 요소를 파악할 수 있습니다.
- <b>계획 모드 (Plan Mode)</b>: Claude가 더 많은 파일을 읽고, 변경 전 전체 계획을 세우도록 합니다.
- <b>심화 모드 (Thinking Mode)</b>: 복잡한 로직이나 디버깅에 사용할 수 있습니다.
- <b>Git 연동</b>: 변경된 파일을 스테이징하고, 커밋 메시지를 자동으로 작성해줍니다.

→ 복잡한 작업일수록 `계획 모드` + `심화 모드`를 함께 쓰면 효과가 좋습니다.

## 🧠 컨텍스트 제어 기능

긴 대화를 하다 보면 Claude가 헷갈릴 수 있습니다. 이를 방지하기 위한 기능들이 있습니다:

- `Escape`: Claude의 현재 응답을 멈춤
- `Escape + Memory`: 반복되는 실수를 막기 위해 메모리 저장
- `Double Escape`: 대화를 되돌아보고 원하는 시점으로 되감기
- `Compact`: 중요한 정보만 요약해 Claude가 혼란을 줄이도록 함
- `Clear`: 대화 내용을 모두 삭제하고 새롭게 시작

## 🔧 사용자 정의 명령 (Custom Commands)

- 프로젝트 내 `.Claude/commands/` 폴더에 `.md` 파일을 만들면 <b>/명령어</b> 형식으로 실행할 수 있는 사용자 명령어를 추가할 수 있습니다.
- `$arguments` 변수를 써서 명령어에 인자를 넘길 수 있습니다.
- 예: `/audit dependencies` 처럼 반복적인 작업을 자동화하는 데 유용

## 🚦 Hook 시스템으로 작업 제어

Hook은 Claude가 <b>도구를 실행하기 전/후에 특정 명령어를 자동 실행</b>하게 하는 기능입니다.

- <b>Pre-hook</b>: 도구 사용 전 실행되며, 작업을 <b>차단할 수도 있음</b>
- <b>Post-hook</b>: 도구 사용 후 실행, 결과를 Claude에게 다시 전달

### 예시:

- `.env` 파일 읽기 차단:
    - `read` 또는 `grep` 도구가 `.env` 파일을 요청하면 Claude가 이를 막습니다.
- 타입스크립트 오류 자동 수정:
    - `tsc --no-emit` 명령을 자동 실행해 타입 오류를 Claude가 바로 고치게 함
- 중복 쿼리 방지:
    - 쿼리 디렉토리에 수정이 생기면 다른 Claude 인스턴스가 기존 쿼리와 비교해 중복 여부를 체크 → 중복이면 Claude에게 피드백 후 기존 쿼리 재사용

## 🌐 Claude MCP 서버 (외부 도구 연동)

MCP 서버는 Claude의 기능을 확장하는 <b>외부 도구 실행 서버</b>입니다.

- <b>Playwright MCP 서버</b>를 사용하면 Claude가 브라우저를 자동으로 제어할 수 있습니다.
- 예: `localhost:3000`에 접속해 UI 테스트 수행, 스타일 개선 등
- MCP 서버는 명령어 한 줄로 추가할 수 있고, 설정 파일에 승인하면 자동으로 사용 가능

---

## 🧬 GitHub 통합

Claude Code는 <b>GitHub Actions에 통합</b>되어 자동화 기능을 수행할 수 있습니다.

- `/install GitHub app` 명령으로 설치
- PR이 올라오면 자동으로 코드 리뷰
- 이슈나 PR에서 `@Claude`로 언급하면 작업을 할당
- MCP 서버와 함께 브라우저 테스트 등도 GitHub 안에서 자동화 가능

---

## 🔌 Claude Code SDK

Claude Code는 터미널뿐 아니라 <b>CLI, TypeScript, Python</b>을 통해도 사용할 수 있습니다.

- SDK는 기본적으로 읽기 전용
- 쓰기 작업(파일 수정 등)은 명시적으로 허용해야 합니다
- 파이프라인이나 자동화 스크립트에 Claude의 지능을 통합할 때 사용하면 좋습니다

---

## ✅ 정리

Claude Code는 단순한 AI 챗봇이 아니라, <b>실제 개발 업무를 도와주는 협업형 AI 개발자</b>입니다.  
정적인 코드 생성뿐 아니라, <b>맥락 파악, 수정 제안, UI 분석, 테스트 자동화, 보안 분석, 반복 작업 자동화</b>까지 수행하며, 확장 가능한 구조로 다양한 개발 팀에 맞게 커스터마이징이 가능합니다.

필요에 따라 <b>도구, 명령어, 후크, 외부 서버(MCP)</b> 를 추가해 계속 진화시킬 수 있으며, 개발자의 생산성을 획기적으로 높이는 도구로 활용할 수 있습니다.
