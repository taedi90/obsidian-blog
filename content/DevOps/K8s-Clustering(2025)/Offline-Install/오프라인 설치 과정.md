## 에이전트 필요 환경
- 리눅스 환경이 기본
	- 윈도우의 경우 "도커 데스크톱" 설치 필요
		- windows 의 hyper-v 추가기능 활성화 및 uefi 하드웨어 가상화 옵션 활성화 필요
		- 네트워크 모드 host 잘 안될 수 있으니 -p 80:80 할 것
- 에이전트 pc 와 클러스터 대상 노드간 다이렉트 통신 또는 프록시 필요
	- 에이전트 -> 클러스터 노드 : ssh port
	- 클러스터 노드 -> 에이전트 : webserver port
