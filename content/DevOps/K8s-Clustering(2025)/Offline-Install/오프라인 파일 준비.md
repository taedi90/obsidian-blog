


커버리지 - rocky9, ubuntu24.04

rocky9 컨테이너에서 

### 필요 사항
- kubespray 바이너리 파일
- 컨테이너 이미지
- 리눅스 패키지

확인해본 결과 [kubespray-offline](https://github.com/kubespray-offline/kubespray-offline) 오픈소스가 있었고, 당장은 이걸 쓰고 추후 ansible 화 하기로 결정했다. (시간 부족 이슈)

추가해야할 사항은
- 컨테이너 이미지 추가
- 패키지 목록 추가 (nvidia 드라이버, cuda 패키지 등)
- kubernetes 버전 지정 변수 추가


순서는
```
# 도커 설치 (ubuntu 패키지 설치를 위해서 필요)
./install-containerd.sh

# 계정에 도커 그룹 추가 (이후 쉘 재접속)
sudo usermod -aG docker {계정명}

# 바이너리, 컨테이너 이미지, rocky9 패키지 다운로드
./download-all.sh

# ubuntu-24.04 도커 이미지 빌드
cd docker 
./build-image.sh ubuntu-24.04

# ubuntu-24.04 패키지 다운로드 (없어서 생성해줌)
./prepare-pkgs.sh
```
로 진행하면 `outputs` 폴더에 파일들이 모두 수집된다.

왜 근데 도커 컨테이너 실행은 docker 를 쓰고 nginx 실행은 containerd 를 사용하게 했을까...?

일단 그래서 오프라인 레포와 레지스트리 서버, 파일 서버를 실행하려면 이렇게 해야한다.
```
./outputs/setup-all.sh


sudo /usr/local/bin/nerdctl ps
```
